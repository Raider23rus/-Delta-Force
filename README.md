# Recoil Control v15.8 (modular)

Компенсация отдачи для мыши с веб-панелью настройки. PowerShell + C# (`SendInput`).

> ⚠️ **Дисклеймер.** Проект предназначен для одиночных игр без античита, собственных приложений и accessibility-задач. Использование в Delta Force, любой игре с EAC/BattlEye/собственным античитом — **нарушение ToS** и риск бана (включая HWID). Автор не несёт ответственности за последствия. Не используйте в мультиплеере.

## Возможности

- Компенсация вертикальной и горизонтальной отдачи через `SendInput` (не устаревший `mouse_event`).
- Рандомизация паттерна (±10% V, ±0.5 px H) — не идеально ровная линия.
- **Скорость** компенсации (1–100) — влияет на паузу между шагами.
- **Профили** — сохранение/загрузка наборов V/H/Speed.
- **Веб-панель** `http://127.0.0.1:8765/` — ползунки, кнопки, Pause, профили.
- **Живое обновление** — значения из веба подхватываются C#-потоком за ~10 мс.
- **Pause/Resume** — F7 или кнопка в вебе.
- **Exit** — F12.
- **Без консольного меню** — только статус и URL, чтобы не мешать.

## Требования

| Компонент | Версия |
|-----------|--------|
| Windows | 10 / 11 |
| PowerShell | 5.1 (встроенный) или 7.x |
| .NET Framework | 4.7.2+ (для `Add-Type` с C# 5) |
| Права | **Администратор** (для `HttpListener` на `127.0.0.1:8765` без `urlacl`) |
| Браузер | Любой современный (Chrome/Edge/Firefox) |
